# EduGenie - AI Learning Assistant

EduGenie is a lightweight AI-powered educational assistant designed to make learning simple, interactive, and personalized.

## Features

- Ask questions and get AI-powered answers
- Simplify complex concepts
- Generate quizzes
- Summarize educational content
- Get personalized learning recommendations

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Jinja2
- Google Gemini API
- LaMini-Flan-T5
